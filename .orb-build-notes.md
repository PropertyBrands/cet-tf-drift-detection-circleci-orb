# Orb Build Notes

## Python Script Heredoc Solution

### Problem
CircleCI's orb packer doesn't allow mixing `<<include()>>` directives with bash heredoc syntax in YAML multiline strings. Attempts like this fail:

```yaml
command: |
  cat <<'EOF' > /tmp/validate_drift.py
  <<include(scripts/validate_drift.py)>>
  EOF
```

### Solution
1. **Source of Truth**: Maintain Python code in `src/scripts/validate_drift.py`
2. **Build Step**: Run `./scripts/generate_python_wrapper.sh` to create `src/scripts/write_validate_drift.sh`
3. **YAML Command**: Use `command: <<include(scripts/write_validate_drift.sh)>>`

The build script wraps the Python code in a heredoc within a shell script, which the orb packer can process correctly.

### Files Involved
- `src/scripts/validate_drift.py` - **Source of truth** (edit this file)
- `src/scripts/write_validate_drift.sh` - Auto-generated wrapper (DO NOT EDIT)
- `scripts/generate_python_wrapper.sh` - Build script
- `src/commands/python_heredoc.yml` - Command definition

### Workflow
```bash
# 1. Edit the Python script
vim src/scripts/validate_drift.py

# 2. Build the orb (generates wrapper + packs)
make build

# 3. Commit both files
git add src/scripts/validate_drift.py src/scripts/write_validate_drift.sh
git commit -m "Update drift validation logic"
```

### Quick Reference
- `make help` - Show all available commands
- `make build` - Generate wrapper and pack orb
- `make validate` - Build and validate orb
- `make clean` - Remove generated orb.yml
